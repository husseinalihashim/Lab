# Terminal Chess Game

A simple command-line chess game written in Python. It features a colorful terminal board using ANSI escape codes, turn-based play, standard piece movement rules, and checkmate detection.

## Features
- Checkered board layout with ANSI background colors
- Move validation for pawns, knights, bishops, rooks, queens, and kings
- Path clearance checks for sliding pieces
- Turn switching between White and Black
- Check and checkmate detection

## How to Run
Make sure you have Python 3 installed, then run:

```bash
python3 main.py
